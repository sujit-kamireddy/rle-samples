# Baked `math_rl` Dataset Snapshot

`train.jsonl.gz` and `validation.jsonl.gz` are generated by
[`build_dataset.py`](../build_dataset.py) from
[`EleutherAI/hendrycks_math`](https://huggingface.co/datasets/EleutherAI/hendrycks_math)
(training split, held-out against `HuggingFaceH4/MATH-500`) and
[`HuggingFaceH4/MATH-500`](https://huggingface.co/datasets/HuggingFaceH4/MATH-500)
(validation split). Both are MIT-licensed.

The snapshot is baked in and checked in here — rather than generated inside
`docker build`, as earlier versions of this sample did — so that building this
image needs no Hugging Face/network access at all, matching `code_rl`'s data
snapshot approach. See `source.json` for row counts/checksums; re-run
`build_dataset.py` (from the repository root, e.g.
`python -m examples.gym.openenv.math_rl.build_dataset --out-dir <dir>`) and
re-gzip the outputs into this folder to refresh the snapshot.
